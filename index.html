MiBackup for Windows

Encrypted backups for all your Windows PCs, managed from one server, set up from one file.

Download MiBackup.exe

Version 0.2.0 · 53 MB · Windows 64-bit

Early test version. Try it with test data first, and don't rely on it as your only backup yet.

How to install

  1. Download this same file for every PC and double-click it. If Windows SmartScreen appears, click More info, then Run anyway. This app isn't code-signed yet.
  2. Click Yes on the permission prompt.
  3. On one PC, choose Server. Add a storage folder and set the default backup settings for new PCs.
  4. On every other PC, choose Client. Check that the code it shows matches the code at the top of the server screen.
  5. On the server, click Approve next to each new PC. Its name appears automatically.
